# v1.1.0 —— 从"一开就是编辑器"变成一个应用

这一版把外壳重做了一遍:**打开先进主页**,左边一条可收起的导航轨(手机上是底部标签栏),
编辑器、下载列表、关于各就各位。顺手修掉了"从主页进编辑器整段动画糊成一团"、
"手机上还是桌面端界面"、"预览音效重复开头/没声音"这几个卡了很久的问题,
并且加上了**应用内更新**:发现新版本可以在软件里直接下载并安装。

## 下载哪个

| 文件 | 平台 | 说明 |
|---|---|---|
| `DeltaForceAnimationEditor-Setup-1.1.0.exe` | Windows x64 | 一键安装包(**推荐**):有进度条、任务栏可见,装完启动约 1 秒 |
| `DeltaForceAnimationEditor-Portable-1.1.0.exe` | Windows x64 | 便携版单文件。首次启动先解压到 `%TEMP%`,加载画面约 15s |
| `DeltaForceAnimationEditor-1.1.0-win-unpacked.zip` | Windows x64 | 免安装版,解压即用(比便携版启动快) |
| `dfae-1.1.0-arm64-v8a.apk` | Android 7.0+ | **release 签名包**,含 `arm64-v8a`。下载后点开安装(需允许「安装未知来源应用」) |

> **Windows 首次运行会有 SmartScreen 提示**(产物没有做代码签名):点「更多信息」→「仍要运行」。

## 这一版改了什么

### 打开先进主页,侧边栏可收起

- **主页 / 编辑器 / 下载列表 / 关于** 四页,主页是默认页;下载列表只在桌面端出现
  (手机的落点是系统相册,那套"定位 / 打开 / 重命名"对 `content://` 没有对应能力)。
- **侧边栏默认收起(56px)**,点右上角箭头或 `Ctrl/Cmd+B` 展开到 176px。
  收起是一次 220ms 的容器变形:宽度、内边距、图标位置一起过渡,文字用 `max-width` 收放,不是硬切。
- 主页**不放动画列表** —— 选动画是编辑器里那件事。主页只回答"现在要干什么":
  版本、主操作、上次打开的那一套。检查更新与保存目录搬到了**关于**。
- 切换页面不会销毁编辑器:预览画布的适配、时间轴、导出参数都保持原样,来回切不跳。

### 全新安装的第一次进编辑器不再糊

从主页点「打开编辑器」时,动画实例若是在**编辑器还隐藏着**的时候建的,内部尺寸会按 0×0 算死,
只把容器显示出来并不会让它重新测量 —— 表现就是整段动画压成一团,必须换一套动画再换回来才恢复。
现在发现这种情况会**自动重建一次实例**(跟你手动做的是同一个动作),实测两边几何与节点数完全一致。

### 手机端是另一套界面(这次真的分开了)

- Tauri 在 Android 上注入的 `window.__DFAE_MOBILE__` 成为端判定的**第一权威信号**。
  以前它只被桥接层用于"保存到相册",UI 从来没读过 —— 所以安卓 APK 里 UA/指针判定一失手,
  整个前端按桌面端渲染,这就是"手机上还是桌面端"的根因。
- 导航轨在手机上变**底部标签栏**,接**系统返回键**(逐级回退,退到主页再按才退出应用),
  同一格再点一次回到顶部;换页有淡入 + 上移 6px 的过渡,选中条从中间长出来。
- 底栏不再贴系统手势区(底部 inset 至少 12px),点击走 `pointerup` + 坐标判定,
  不依赖 `click` 合成;关于页底部有**现场数据行**,点不动时可以直接看落点。
- 手机上打开动画画廊**不再自动聚焦搜索框**(以前会立刻弹输入法,顶掉半屏)。

### 预览音效重写(WebAudio)

lottie 每帧都会检查「音频位置与动画时间是否对齐在 100ms 内」,不齐就重排。手机上 `<audio>`
的 `currentTime` 会因缓冲滞后,于是**每帧 seek 回开头** —— 这就是"一直重复 0~0.2s"。
现在预览音效走 `AudioContext` + `AudioBufferSourceNode`:位置由 `AudioContext.currentTime` 推算,
只有真实跳变(>250ms)才重排音源;解码结果按资源缓存;首次手势统一解锁全部音轨。
实测播放 6 秒音源创建次数恒为 2(每层一次),修复前会持续增长。

### 应用内更新(桌面安装版)

关于页「检查更新」发现新版本后,可以直接点**下载并安装**:

- 主进程流式下载安装包到 `%TEMP%\dfae-update`,带进度条与取消;
- 校验大小 + PE 头(MZ)+ 下载站点白名单(只允许 gitcode.com / github.com 等);
- 校验通过后 detached 启动 NSIS 安装器并退出自己,装完自动拉起新版。

**每次启动会自动检查一次更新**(可在关于页关掉);发现新版本时侧栏「关于」会亮一个小点。
便携版与手机端仍然是「前往下载」(便携版每次启动解压到 `%TEMP%`,没有固定安装目录可自替换)。

## 已知说明

- 手机端的音效需要**一次用户手势**才能出声(WebView 的硬性自动播放策略,任何实现都绕不过);
  手势之后所有音轨一起解锁,不会再出现"有的层没解开"。
- 真机上的音效与返回键行为仍需要更多机型反馈:排障时请看关于页的现场数据行。

# v1.0.4

这一版修的是**「改完文字再导出,透明 AVI 打开什么都不显示」**:改成表外字之后,canvas 渲染器的文字层
拿不到字形,连带把它自己的透明度/变换状态带歪,整帧(连底框、描边这些纯形状图层)都变成全透明 ——
文件结构完全正常,所以播放器只是"黑着/什么都不显示"。现在这类导出会自动改走 **SVG 逐帧光栅化**
(和预览完全一致的画面),预览遇到同一份数据也会自己切回 SVG 渲染器,不需要做任何设置。

同时这一版把手机端拖动/捏合的**掉帧**压下去了:手势期间只在下一帧结算一次视图、舞台尺寸不再每帧重读
布局、拖动时临时提升为独立合成层并收掉毛玻璃。

## 这一版改了什么

### 导出修复(重点)

- **改字后导出透明 AVI 全透明 / MP4 只剩背景色**:现在会自动改用 SVG 逐帧光栅化导出,画面与预览一致。
  判定只看三件事(有文字层 + 现在没有字形表 + 这套动画出厂时带过字形表),所以**撤离 / 位置暴露 /
  核电站**这三套没有字形表的动画不受影响,导出速度与以前一样。
- **预览也会自动纠正**:如果你正用 canvas 渲染器,改成表外字之后它会自动切回 SVG 渲染器并在状态栏说明,
  不会出现"画面突然全没了"。
- **导出浮层会先说明慢在哪**:这类导出会逐帧光栅化,比平时慢一些;透明 AVI 本身是无压缩的
  (约 8 MB/帧,2560×1024 的地图标题整段约 3.4 GB),浮层里都写了。

### 手机端

- **拖动 / 捏合掉帧**:触屏 `pointermove` 能到 120–240Hz,原来逐条事件都去算视图并写 DOM,同一帧重复干几次;
  现在只记"手指在哪",结算放下一帧(getBoundingClientRect 每帧强制布局也一并干掉 —— 实测单指平移
  54 次移动里曾强制 78 次布局)。
- **手势期间画布提升为独立合成层**:改 transform 不再让近 900 节点的 SVG 整层重新光栅化;松手立刻摘掉,
  不常驻占大贴图。手势期间顺带收掉压在画布上的毛玻璃(`backdrop-filter`),松手恢复。
- **松手惯性 / 长按复位的边角**:抬起时补结算最后一次移动,长按复位后松手不会跳回原位;惯性按速度采样,
  停顿超过 80ms 就丢掉旧速度(慢速拖动不再"飘")。

### 工具与文档

- 新增回归脚本 `tools/verify-maptitle-transparent-avi.mjs`:改字 → 导出一份小体积透明 AVI → 从文件里
  解帧核对 alpha 与白色文字像素(会临时把出点压到 41 帧,避免动辄 3.4 GB 的成品)。
- 新增 `tools/mobile-perf.mjs`(手势帧率/强制布局次数)、`tools/verify-mobile-touch.mjs`(触屏交互断言)。
- `docs/FEATURES.md` 的「兼容导出」补上这条判定的根因与三个条件;README 常见问题加了一条对应问答。

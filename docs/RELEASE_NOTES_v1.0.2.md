# v1.0.2 

本次主要更新了电脑端的加载画面

## 下载哪个

| 文件 | 平台 | 说明 |
|---|---|---|
| `DeltaForceAnimationEditor-Portable-1.0.1.exe` | Windows x64 | 便携版单文件,约 88 MB。首次启动会先解压到 `%TEMP%`,先显示加载画面约15s,加载完毕弹出窗口 |
| `DeltaForceAnimationEditor-1.0.1-win-unpacked.zip` | Windows x64 | 免安装版,解压即用(比便携版启动快) |
| `dfae-1.0.1-arm64-v8a.apk` | Android 7.0+ | **release 签名包**,27 MB,含 `arm64-v8a`。手机上下载后直接点开安装即可(需允许「安装未知来源应用」) |

> **Windows 首次运行会有 SmartScreen 提示**(产物没有代码签名):点「更多信息」→「仍要运行」。

## 这一版有什么

### Android 端

- **导出直接进系统相册**:落在 `Movies/三角洲行动动画编辑器/`,不需要任何存储权限(Android 10+)。
- **移动端界面**:竖屏是底部可拖拽面板 + 分区芯片,横屏 / 平板是右侧停靠栏;画布支持单指拖动平移(带惯性)、双指捏合缩放、双击放大/适配、长按复位、单击播放暂停。
- **平板自动锁横屏**(`smallestScreenWidthDp >= 600`)。
- 手机端不提供「下载列表」:落点是相册,那套针对文件路径的操作没有对应能力。

### Windows 端

- 与网页版界面、编辑能力、导出规格完全一致,只是套了 Electron 外壳:双击即用、完全离线、导出不被后台节流。
- 下载列表 + 下载历史:产物落在系统「下载」文件夹的应用子目录,历史存在 `%APPDATA%`,删掉软件或搬到别的盘都不会丢。
- 三条老牌能力保持不变:窗口大小记忆、单实例、导出完成系统通知(点通知直接定位文件)。

# v1.1.4 —— 两套动画补上音效 + AE 投影对齐

这一版给**任务弹窗动画(#004)**和**首领入侵/曼德尔砖标题动画(#009)**都接上了内置音效,
另外把「AE 投影(ADBE Drop Shadow)」的渲染口径整体对齐到了 After Effects,
预览与导出成片的阴影方向、软硬终于和 AE 一致。

## 这一版改了什么

### 两套动画补上内置音效

- **任务弹窗动画(#004)**:内置 `misson.wav`(48kHz 立体声,约 4.4s)。画面约 3.57s(214 帧 @60fps),
  音频比画面长,导出时按画面时长截断,不会把音轨拖长。
- **首领入侵 / 曼德尔砖标题动画(#009)**:内置 `UI_SOL_Said_Entry_Banner_611300523.wav`
  (48kHz 立体声,约 3.25s,与 188 帧 ≈ 3.13s 基本等长)。
- 两套音效都改成**随动画数据一起预取**(切到这套动画才开始加载,不拖慢启动),
  并且把素材 JSON 里指向素材目录的相对文件名改写成站点真实资源地址 —— 以前预览会静音、导出也找不到音轨。
- 音量沿用编辑器统一口径(数据里给满音量,运行时按全局音量系数调低),不会突然比其它动画响。

### AE 投影(ADBE Drop Shadow)渲染对齐

以前 22 处投影**方向整体偏了 90° 并镜像**(133° / 135° / 165° / 180° / 195° / 102° 的阴影全跑到左上),
柔和度也比 AE 软一倍,这就是「预览/导出和 AE 看起来对不上」的主因。这一版逐项对齐:

- **方向**:改成 AE 口径(0° 指正上方、顺时针为正),`dx = 距离·sin θ`、`dy = −距离·cos θ`;
- **柔和度**:SVG 侧取 `柔化/4`(与 lottie 原生投影的 `stdDeviation` 同口径),不再糊成一片;
- **Canvas 导出**:投影改到图层真正绘制的那一步设置阴影,并且按当前变换矩阵把偏移/模糊换算到设备像素 ——
  预览的缩放/高分屏与导出成片从此一致(以前缩放 200% 时阴影不跟着放大);
- **不再重复绘制**:去掉「画两遍」的做法,半透明图层不会被叠两次(50% 透明度以前会被叠成 75%,淡入淡出的文字发亮);
- **容错**:投影参数被做成关键帧时取首关键帧,不会再整层丢掉投影;效果开关(`en:0`)按 AE 原样跳过。

### 界面与素材

- 侧栏导航轨换成 Lucide 线性图标,收起态对齐修正;
- 任务弹窗 / 曼德尔砖两套动画数据更新(接入音效资源)。

## 已知说明

- Windows 产物没有代码签名,首次运行会有 SmartScreen 提示;安装版支持应用内更新,便携版与手机走「前往下载」。

# v1.0.3

这一版先修「手机端图标不对」:**装到手机上的应用图标原来还是 Tauri 模板自带的黄+青默认图标**,
现在换成了品牌标志(深灰底板 + 近白标志),网页端、iOS 主屏、Android 自适应图标与 Android 13
主题图标都统一了。

## 下载哪个

| 文件 | 平台 | 说明 |
|---|---|---|
| `DeltaForceAnimationEditor-Setup-1.0.3.exe` | Windows x64 | 一键安装包(**推荐**):有进度条、任务栏可见,装完启动约 1 秒 |
| `DeltaForceAnimationEditor-Portable-1.0.3.exe` | Windows x64 | 便携版单文件。首次启动先解压到 `%TEMP%`,加载画面约 15s |
| `DeltaForceAnimationEditor-1.0.3-win-unpacked.zip` | Windows x64 | 免安装版,解压即用(比便携版启动快) |
| `dfae-1.0.3-arm64-v8a.apk` | Android 7.0+ | **release 签名包**,含 `arm64-v8a`。下载后点开安装(需允许「安装未知来源应用」) |

> **Windows 首次运行会有 SmartScreen 提示**(产物没有代码签名):点「更多信息」→「仍要运行」。
>
> 已经在用旧版的手机用户:覆盖安装后如果桌面图标没变,把旧图标删掉再拖一次 / 重新「添加到主屏幕」——
> 部分启动器会缓存图标。

## 这一版改了什么

### 手机端

- **修复桌面图标是默认黄蓝图标**:各密度 launcher 图标(圆形/方形)、Android 8+ 自适应图标、
  Android 13 主题图标全部换成品牌标志;网页端补上 PNG favicon、`apple-touch-icon` 与
  `manifest.webmanifest`,iOS / Android 的「添加到主屏幕」不再退回浏览器默认链接图标。
- 触屏命中区按 40px 补齐:主题开关(外观不变,只扩命中区)、动画选择器、侧栏分区芯片。
- 移动端浏览器地址栏 / 任务卡片颜色跟随应用主题(深色 `#242424` / 浅色 `#eaeaf0`)。

### 界面修复

- **窄桌面窗口(≤480px)的顶栏主次**:动画选择器独占一整行,不再被「未使用 AI」声明挤到 124px。
  注意这条只影响网页版被拖窄的情况;手机端用的是另一套顶栏(两行网格),本来就没这个问题。
- **动画画廊 / 下载列表头部**:480px 以下折成两行,关闭按钮不再被挤出面板(之前 470px 时还差 2px)。
- 三个模态浮层的键盘焦点被限制在浮层内(之前连按 Tab 第 10 下就跑到被遮住的页面上);
  导出浮层补上对话框语义,导出进度与数据加载进度补 `progressbar` 语义,状态栏补 `live region`。

### 工具与文档

- 新增 `npm run icons:app`:从 `public/logo.svg` 一次生成网页 / PWA / Android 全套图标。
- 新增 `tools/verify-app-icons.mjs`(像素级断言:默认黄+青出现一个就算失败)与
  `tools/verify-dialog-a11y.mjs`(桌面 / 手机两套前端的浮层与窄屏断言)。
- 修好两个会误导人的工具:`ui-audit` 的「浅色」分支之前点不到主题按钮、一直在量深色;
  `shot.mjs` 的 `--theme` 之前只模拟系统偏好,应用主题是显式存的;并新增 `--ui mobile`。

# v1.1.6 —— UI 图标提取(从游戏 pak 里抽透明底 PNG)

这一版的主线是侧边栏新增的「图标提取」:直接读游戏目录下的 pak,把 UI 图标(任务、武器、干员、模式……)
按名字解出来,裁成透明底 PNG,支持搜索、分类、染色与批量导出。另外修了一个手机端图片导出的落盘问题。

## 下载哪个

| 文件 | 平台 | 说明 |
|---|---|---|
| `DeltaForceAnimationEditor-Setup-1.1.6.exe` | Windows x64 | 一键安装包(**推荐**):安装器有进度条,装完启动约 1 秒 |
| `DeltaForceAnimationEditor-Portable-1.1.6.exe` | Windows x64 | 便携版单文件。首次启动先解压到 `%TEMP%`,加载画面约 15s |
| `DeltaForceAnimationEditor-1.1.6-win-unpacked.zip` | Windows x64 | 免安装版,解压即用(比便携版启动快) |
| `dfae-1.1.6-arm64-v8a.apk` | Android 7.0+ | **release 签名包**,含 `arm64-v8a`。下载后点开安装(需允许「安装未知来源应用」) |

> **Windows 首次运行会有 SmartScreen 提示**(产物没有做代码签名):点「更多信息」→「仍要运行」。

## 这一版改了什么

### 新功能:UI 图标提取(桌面端)

侧边导航轨多了「图标提取」,和音频提取共用同一份「游戏目录」设置。

- **一条龙**:选/自动定位游戏目录 → 「扫描 UI 图标包」建索引 → 搜索 → 预览 → 导出 PNG。
  索引与音频提取一样会缓存,换游戏版本(或 pak 有更新)时才需要重扫。
- **搜索式分页**:每页 120 个,底部是「‹ 上一页 1 2 3 下一页 ›」页码条。
  按**名称分类**筛选(取名字第一个下划线前的段,约 150 类),不是按图集目录分组 —— 找「HUD」「TaskSystem」这类更直观。
- **染色**:原色 / 银灰 / 深灰 / 纯黑 / 自定义颜色(白色 sprite × 目标色),一次设置对预览和导出同时生效。
- **导出**:单张直接导出;「导出当前筛选全部」会把当前条件下的所有图标一起导出到指定目录,
  结果卡给出文件数与「打开文件夹」,失败时给原因与「再试一次」。
- **兼容多种图集格式**:实测 179 个 UI 图集中 `BC7` / `DXT5` / 未压缩 `BGRA` 三种都有,全部支持;
  图集尺寸也不一定被补齐到 2 的幂(实测有 1648×960),不会再因此整批解不出来。
- 个别图标在图集里本来就是空白,或有素材只在移动端包里的,会明确标「空白」/「无图」并给出原因,不会一直转圈。

> 图标提取**仅桌面端**:要读 pak、解 Oodle、再解 BC7,手机端导航里不会出现这个入口。

### 修复

- **手机导出 PNG 落进视频相册**:Android 端原先 PNG 一律按 `video/mp4` 写进 MediaStore,系统会把它补成
  `xxx.png.mp4` 并塞进 Video 集合。现在图片按 `image/*` 落到「图片」相册,文件名保持 `.png`。
- 图片编辑器的 PSD 素材更新(结算图与合同图),首屏解析与显示细节同步调整。

### 构建与验证

- 打包文件清单补上 `texture2ddecoder-wasm`(BC7 解码),Electron 31 主进程里走兼容加载器(
  官方入口是 ESM 胶水,主进程直接 require 会报错) —— 否则打包版的图标预览与导出会全挂。
- 新增 `tools/check-icons-parser.mjs`(sprite 解析、三种图集格式、与真机图集金标逐像素比对,本机没装游戏自动跳过真机部分)
  与 `tools/verify-icons.mjs`(假桥跑通整页交互,无需游戏)。

## 已知说明

- **图标提取只在桌面端出现**;手机端只有主页 / 动画编辑器 / 图片编辑器 / 日志 / 关于。
- 图标提取需要本机装有三角洲行动(读到 pak);首次扫描约 2~4 秒,大图集解码首次预览会稍慢。
- 动画编辑器、图片编辑器(含名片透视)、音频提取与上一版一致。
- 名片原图需要联网(GitCode);离线或拉取失败时会用 160px 缩略图顶替,放大后偏糊。
- Windows 产物没有代码签名,首次运行会有 SmartScreen 提示;安装版支持应用内更新,便携版与手机走「前往下载」。
- 编辑结果只在内存里:刷新页面即回到素材原样,要带走效果请导出文件。

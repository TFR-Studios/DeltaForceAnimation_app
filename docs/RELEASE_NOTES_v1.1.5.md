# v1.1.5 —— 图片编辑器(结算图 PSD)+ 名片透视

这一版是继动画编辑器之后加的**第二个编辑器**:直接编辑应用内置的结算图 PSD —— 改文字、换背景、把一张
人物名片摆到手机上,再导出 PNG。另外侧边栏新增「音频提取」,桌面端可以直接从游戏 pak 里抽 Wwise 音频。

## 下载哪个

| 文件 | 平台 | 说明 |
|---|---|---|
| `DeltaForceAnimationEditor-Setup-1.1.5.exe` | Windows x64 | 一键安装包(**推荐**):安装器有进度条,装完启动约 1 秒 |
| `DeltaForceAnimationEditor-Portable-1.1.5.exe` | Windows x64 | 便携版单文件。首次启动先解压到 `%TEMP%`,加载画面约 15s |
| `DeltaForceAnimationEditor-1.1.5-win-unpacked.zip` | Windows x64 | 免安装版,解压即用(比便携版启动快) |
| `dfae-1.1.5-arm64-v8a.apk` | Android 7.0+ | **release 签名包**,含 `arm64-v8a`。下载后点开安装(需允许「安装未知来源应用」) |

> **Windows 首次运行会有 SmartScreen 提示**(产物没有做代码签名):点「更多信息」→「仍要运行」。

## 这一版改了什么

### 图片编辑器:直接改结算图(桌面端)

侧边导航轨多了「图片编辑器」,和动画编辑器互不影响(来回切页都不销毁)。

- **免选文件**:进入页面自动载入内置结算图 PSD(约 11.7MB)。解析完成后状态行给出「宽×高 · 文字图层数 · 解析耗时」,
  失败了停在空状态,点「重新载入示例」再试。
- **文字图层**:按 Photoshop 面板顺序列出全部文字图层,改**内容 / 颜色 / 透明度**。
  只改颜色时直接拿原字形像素当蒙版填新色(不会因重排而变形);改内容才按图层字体重排。
- **背景切换**:内置 4 张结算背景(来自 DFAsset 的 `settlement/`,随应用打包、离线可用)。
  原背景的手机屏幕是透明挖孔,换背景时会用下层屏幕内容重新合成并补黑 —— 不会露出透明缝。
- **画布操作**:滚轮以鼠标位置为中心缩放、按住拖动平移、双击复位;右下角有缩放读数与「适应」,
  选中图层的虚线框画在屏幕坐标里,缩放时始终 1.5px。
- **撤销**:单层「恢复原样」或顶部「撤销修改」(全部)。
- **导出 PNG**:按 PSD 原尺寸合成,透明区域保持透明。导出中按钮显示「正在导出…」,
  完成后结果卡给出文件名 + 「打开文件夹」(直接在资源管理器里定位到文件),产物同时登记到下载列表。

### 名片:190 张人物图,等比 / 自由 / 透视三种摆法

- 素材来自 DFAsset 的 `BusinessFiller`(147 张)与 `Skin`(43 张),选择器支持**搜索、分类、方向键切换**;
  打包里只带清单与 160px 缩略图(约 1.7MB),**原图在选中时才从 GitCode 拉取并缓存**,断网回退到本地缩略图。
- **等比**:锁定原图宽高比;**自由**:宽高独立;**透视**:四角各自拖动产生形变(默认就是一组对好手机屏幕的透视四角)。
- 框内拖动整体平移、顶部圆点绕中心旋转(按住 Shift 每档 15°);
  读数区按模式切换:等比 / 自由显示 X / Y / 宽 / 高 / 宽高% / 角度,透视显示四角坐标。
- 名片**只保留手机屏幕挖孔内的像素**,视觉上位于边框与 HUD 之下,不会盖住边框;导出时同样裁切并垫黑底。
- 「复位」回到默认透视四角,「恢复默认」清掉名片。

### 音频提取(桌面端)

侧边栏新增「音频提取」:直接读游戏目录下的 pak,解析 Wwise 索引后用内置 `vgmstream` 解码,
支持**按分类筛选**、试听与导出。密钥走标准 `AESKey1.json`;修掉了 pack 前缀过滤导致的整包漏扫
(14,470 条 → 80,759 条),并补齐了「其他」分类里漏掉的配乐。

### 下载与导出链路

- 导出结果卡与下载列表的行为对齐:成功给文件名与「打开文件夹」,失败给原因与「再试一次」。
- 补了 `verify-export-fallback` 回归(AAC / Opus / 无 WebCodecs / 移动端下载门禁),编码降档链不再只靠手测。

## 已知说明

- **图片编辑器只在桌面端出现**;手机端只有主页 / 动画编辑器 / 日志 / 关于。
- 图片编辑器只编辑**内置结算图**并导出 **PNG**:不提供打开其它 PSD,也不导出 PSD。
- 名片原图需要联网(GitCode);离线或拉取失败时会用 160px 缩略图顶替,放大后偏糊。
- 原图缓存在本机 Cache Storage 里,按素材版本失效;清缓存后首次选中会重新下载。
- Windows 产物没有代码签名,首次运行会有 SmartScreen 提示;安装版支持应用内更新,便携版与手机走「前往下载」。
- 编辑结果只在内存里:刷新页面即回到素材原样,要带走效果请导出文件。

# v1.1.1 —— 第九套动画 + 一键重置

这一版加了第 9 套动画 **首领入侵/曼德尔砖标题**,并把日常最常用的两件事补齐:
每套动画的**一键重置**,以及发现新版本时的**全屏更新提示**。
另外修掉了安卓上「关于页被认成桌面版」的判定问题。

## 下载哪个

| 文件 | 平台 | 说明 |
|---|---|---|
| `DeltaForceAnimationEditor-Setup-1.1.1.exe` | Windows x64 | 一键安装包(**推荐**):安装器有进度条,装完启动约 1 秒 |
| `DeltaForceAnimationEditor-Portable-1.1.1.exe` | Windows x64 | 便携版单文件。首次启动先解压到 `%TEMP%`,加载画面约 15s |
| `DeltaForceAnimationEditor-1.1.1-win-unpacked.zip` | Windows x64 | 免安装版,解压即用(比便携版启动快) |
| `dfae-1.1.1-arm64-v8a.apk` | Android 7.0+ | **release 签名包**,含 `arm64-v8a`。下载后点开安装(需允许「安装未知来源应用」) |

> **Windows 首次运行会有 SmartScreen 提示**(产物没有做代码签名):点「更多信息」→「仍要运行」。

## 这一版改了什么

### 新动画:首领入侵/曼德尔砖标题(第 9 套)

- 画布 1920×1080 / 60fps / **188 帧 ≈ 3.13s**,无音效;
  画面是一条深色 HUD 标题条 + 白色标题文字「安全总监莅临」+ 一张德穆兰立绘 + 一组红白形状层
  (轨道遮罩做开合 / 扫光的观感)。
- **立绘画在整组 HUD 之上**:载入时自动把立绘图层提到最上层,不会再被标题条 / 扫描线盖住。
- **立绘可以调色**:侧栏「图片图层」里给立绘选颜色、调不透明度或一键重置。
  内置立绘本身是一张纯黑剪影,选颜色后会**整片上色**(预览与导出都生效),所以颜色一定看得见;
  「图标选择」里还能换图 / 上传自定义图,换图后颜色回到原样,切走再切回会保留之前的颜色。
- **编辑区更清爽**:`comp_0` / `comp_1` 两份预合成内部的所有图层,以及顶层的纯黑垫片「形状图层 25」,
  不再出现在右侧编辑列表里 —— 只影响编辑列表,**画面和导出完全不变**。
- 顶栏动画画廊、搜索与数字键 **9** 都能直接切到它。

### 一键重置(每套动画)

右侧编辑区顶部新增**吸顶**的「一键重置」按钮(检查器的第一个元素,与「导出视频」同级的主操作):

- 点一下把当前动画的文字 / 颜色 / 图标 / 时长 / 二次扫描 / 不透明度 / 弹窗 / 预设等改动全部清掉,
  按出厂数据重新载入;说明行与状态栏都会写「已恢复「X」的默认状态」。
- 导出进行中不会执行(避免动到正在逐帧读取的那份数据),会先提示你等导出结束。

### 全屏更新提示

检查到新版本时,不再只亮关于页的一个小点,而是盖住整屏把选择摆到面前:

- **桌面**:居中卡片(与导出浮层同一套视觉);**手机**:占满整屏的面板,主操作贴底、拇指够得着。
- 安装版可以**下载并安装**(应用内下载 + 进度条 + 校验后启动安装器);便携版 / 手机 / 网页给「前往下载」。
- 「稍后再说」本次不再打扰;「跳过这个版本」会记住,**同一版本永不再弹**,换版本才会再提示。
- 启动时的自动检查对同一版本只弹一次;你手动点「检查更新」仍然可以再看到提示;Esc 可关,焦点不会跑出浮层。

### 修复

- **安卓上关于页不再被认成桌面版**:渠道判定改为「移动端优先」,手机显示「手机版」,不再露出只有桌面才有的
  「保存目录」;更新检查也会据此去挑 APK,而不是把 Windows 安装包塞给手机。
- 首页与文档里的「八套」文案统一更新为「九套」。

## 已知说明

- Windows 产物没有代码签名,首次运行会有 SmartScreen 提示;安装版支持应用内更新,便携版与手机走「前往下载」。
- 手机端音效仍需要一次用户手势才能出声(WebView 的自动播放策略),手势之后所有音轨一起解锁。
